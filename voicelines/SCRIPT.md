# Voice line script (50)

Each entry: target filename, then the line to paste into ElevenLabs.

Save MP3s into `voicelines/raw/` using the listed filename, then run
`tools/convert_voicelines.ps1` to produce the 24 kHz mono 16-bit `.wav`
files in `voicelines/wav/`. Copy those to the SD card under `0:/voicelines/`.

Use the same voice and same generation settings for all 50 — drift in
voice between lines breaks the illusion.

---
